# Full Drift UI

The main UI file (`index.html` / `public/index.html`) is ~155KB.

## Option A — from the ZIP
Use **WebOS-Scramjet-flat.zip** from the project chat / release and copy `public/index.html` here.

## Option B — local
After `npm start`, place the latest `index.html` in `public/index.html`.

## Models (recommended)
- **Drift 1.0** — Groq Llama 70B
- **Drift 1.1** — DeepSeek R1
- **Drift 1.2** — Gemini Flash
- **Drift 1.3** — Qwen 72B
- **Drift 1.4** — Llama 70B (OpenRouter)

## Worker secrets
Set on Cloudflare: `GROQ_KEY`, `OPENROUTER_KEY`, `YT_KEY` (optional).
